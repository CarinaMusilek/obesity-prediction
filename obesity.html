1. Dataset Selection

The dataset is from a survey on obesity with 2111 observations. The goal is to find a way to predict obesity based on the given covariables. Four explanatory variables were omitted due to improper explanation of the encoding. If necessary, the variables were converted to factors.

The dataset now consists of the following variables:

  • Gender: Gender
  • Age: Age
  • Height : in metres
  • Weight : in kgs
  • family_history : Has a family member suffered or suffers from overweight?
  • FAVC : Do you eat high caloric food frequently?
  • NCP : How many main meals do you have daily?
  • CAEC : Do you eat any food between meals?
  • SMOKE : Do you smoke?
  • SCC : Do you monitor the calories you eat daily?
  • CALC : How often do you drink alcohol?
  • MTRANS : Which transportation do you usually use?
  • y : Is the person obese? (variable of interest)
data <- read.csv("data/Obesity prediction.csv")

To begin with, a bar chart of the variable Obesity is plotted. This variable initially hat 7 values ranging from “insufficient weight” to “obesity type III”. However, for simplicity reasons, it was summarized in a variable y which is 1 if the person is obese (obesity level I to III, here depicted in orange) and 0 otherwise (insufficient weight to overweight level II, here green).

data <- cbind(data[ , -length(data)], y)

The next plot shows the relationship between height and weight and the group of the data point (obese or not obese). The two groups seem to be almost linearly seperable which is due to the fact that y is calculated from exactly those covariables. The variables weight and height are therefore not considered in the further analysis since obesity is diagnosed based on the body mass index which is calculated using these exact covariables. When fitting a decision tree, these two would dominate the most important nodes and effects of other covariables would go unseen.

Note that the default value for mtry for classification is \(\sqrt{p}\) where p is the number of predictors. In this case, 3 predictors are tried at each split.

4. Model Comparison

4.1 Receiver Operating Characteristic (ROC) Curve

From the outputs in section 3 it can be seen that the random forest model has the highest accuracy on the test data. However, there are other options to compare classification models, for example the Receiver Operating Characteristic (ROC) Curve where the false positive rate is plotted against the true positive rate. A diagonal line with intercept 0 and slope 1 (here in grey) shows the ROC curve of a model that randomly assigns groups. The better the model the bigger the distance between the ROC curve and this line.

# decision tree
ROCRpred <- prediction(as.numeric(predictions_tree) - 1, test$y)
ROCRperf <- performance(ROCRpred, measure = "tpr", x.measure = "fpr")
plot(ROCRperf, lwd=2, col = "green3", main = "ROC Curves")

# bagging
ROCRpred1 <- prediction(as.numeric(predictions_bag) - 1, test$y)

4.2 Area under the Curve

The area under the ROC curve (AUC) is also a measure for model performance which is considered to be more adequate for judging model performance than accuracy. The closer the AUC is to one, the better is the model.

auc <- performance(ROCRpred, measure = "auc")
auc <- auc@y.values[[1]]
auc1 <- performance(ROCRpred1, measure = "auc")
auc1 <- auc1@y.values[[1]]
auc2 <- performance(ROCRpred2, measure = "auc")
auc2 <- auc2@y.values[[1]]
auc3 <- performance(ROCRpred3, measure = "auc")
auc3 <- auc3@y.values[[1]]

cbind("decision tree" = auc, "bagging" = auc1, "random forest" = auc2, "boosting" = auc3)
##      decision tree   bagging random forest  boosting
## [1,]     0.8378527 0.8814151     0.8825571 0.8658755

The individual decision tree has the smallest AUC and is therefore not as good as the other models. In this example, random forest has the largest AUC value and therefore seems to be the best model for the data at hand. The AUC value as well as the ROC curve of the boosting model have to be treated with caution since the performance of a boosting model largely depends on the tuning parameters which were not found with cross validation for this paper.

5. Conclusion

The aim of this project was to find a classifier to determine whether a person is obese or not based on characteristics such as family history, age, gender and eating habits. To do this only tree based methods were used. A decision tree, a bagging model, a random forest and finally a boosting model were fitted to the data and their performance was evaluated on a test set finding that random forest had the highest accuracy among the fitted models. Finally, the models were compared using ROC curves and the AUC measure. Random forest was still found to be the best model for the data at hand since its AUC is the closest to 1.
